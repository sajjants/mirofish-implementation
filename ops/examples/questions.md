# Questions for the Riverton example

Each '## Q<n>' section is one simulation question. The first line after the id is the title.

## Q1: How will public opinion on Proposal 14 develop before the council vote?
Focus on residents, depot staff, local businesses and the council members.

## Q2: Which groups will resist the closure most actively, and how?
Consider organised action, public statements and coalitions between groups.
